# 🎓 AI 스터디 튜터

전 과목 1:1 AI 튜터 웹앱 — 국어 · 영어 · 수학 · 사회 · 과학 · 한국사 · 인공지능기초 (+ 직접 입력)

내 무료 Google AI Studio(Gemini) API 키로 브라우저에서 직접 동작하는 정적 웹앱입니다. 서버가 없고, API 키와 모든 학습 기록은 **이 기기의 localStorage에만** 저장됩니다.

## 바로 쓰기

1. https://aistudio.google.com/apikey 에서 **무료 API 키**를 만듭니다. (카드 등록 없음)
2. 앱 우측 상단 **API 키** 버튼 → 키를 붙여넣고 **저장하고 연결 테스트**.
3. 사용 가능한 Flash 모델을 자동으로 찾아 연결합니다. (2.5-flash → 2.5-flash-lite → 3-flash-preview → 3.5-flash-lite → 3.1-flash-lite 순 폴백)

## 기능

| 탭 | 내용 |
| --- | --- |
| 홈 | 오늘 목표 XP, 연속 학습(🔥), 리그 티어, 데일리 두뇌 챌린지, 배지 |
| 튜터 | 단계별 1:1 과외 / 핵심 정리 모드, 문제 사진·PDF·TXT 첨부, 음성 질문, 답변 읽어주기, KaTeX 수식 |
| 퀴즈 | 자료·단원 기반 객관식/단답형, 즉시 채점·해설, 제한시간 모의고사, 오답 약점 요약 |
| 계획 | 시험 날짜(D-day)와 범위로 날짜별 학습 계획 + 체크리스트 진도 |
| 카드 | 앞/뒤 플래시카드, 모르겠음·헷갈림·완벽히 암기 상태 저장 |
| 오디오 | 복습 팟캐스트(대화형/강의형, 배속·대본 따라가기), 구술 시험(마이크 답변 + AI 채점) |
| 실험실 | 이차함수·삼각함수·포물선 운동·정규분포 내장 시뮬레이션, AI가 만드는 맞춤 인터랙티브 HTML |
| 리그 | 주간 XP 리그(브론즈~다이아몬드), 친구 코드/링크 랭킹, AI 스터디 메이트, 배지, 통계 |

## 리그 규칙

- 이번 주(월~일) 획득 XP로 티어가 정해집니다: 브론즈 0 · 실버 100 · 골드 250 · 사파이어 500 · 루비 900 · 다이아몬드 1500
- 하루 목표 XP를 채우면 연속 학습일이 이어집니다. (스트릭)
- 친구 랭킹은 서버 없이 **공유 코드**로 동작합니다. 내 코드/링크를 보내고, 친구 코드를 붙여넣으면 이 기기 랭킹에 스냅샷으로 표시됩니다.

## 기술

- 순수 HTML/CSS/JS (ES modules), 빌드 없음
- Gemini `generativelanguage.googleapis.com/v1beta` REST, 브라우저 직접 호출 (`x-goog-api-key`)
- KaTeX(수식), PDF.js(자료 텍스트 추출), Web Speech API(음성 인식/합성)
- AI 시뮬레이션은 `iframe sandbox="allow-scripts"` 안에서만 실행 (부모 페이지 접근 불가)

## 개인정보

- API 키·대화·기록은 모두 localStorage에만 저장되고 어떤 서버로도 보내지 않습니다. (요청은 Google Gemini API로만)
- 학교 공용 PC에서는 사용 후 **키 삭제**를 눌러 주세요.
- 리그 → 데이터 → 기록 내보내기/초기화로 관리할 수 있습니다. (키는 내보내지 않음)
