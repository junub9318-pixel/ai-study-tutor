# 🎓 AI 스터디 튜터

전 과목 1:1 AI 학습 앱 — 국어 · 영어 · 수학 · 사회 · 과학 · 한국사 · 인공지능기초 (+ 직접 입력)

내 무료 Google AI Studio(Gemini) API 키로 브라우저에서 직접 동작하는 정적 웹앱입니다. 서버가 없고, API 키와 모든 학습 기록은 **이 기기의 localStorage에만** 저장됩니다.

## 시작 흐름 (온보딩 7단계)

1. **Gemini API 키 연결** — [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에서 무료 키 발급 → 붙여넣고 연결 테스트 (사용 가능한 Flash 모델 자동 탐색). 확인 중에는 버튼과 상태 줄에 정원형 인라인 스피너만 돌고 레이아웃이 흔들리지 않습니다.
2. **국가 · 학년 · 나이 · 학기 · 학교 확인** — 국가, 교육 단계(초/중/고/대), 학년(나이 자동 제안 · 수정 가능), 학기(1학기 / 2학기), 학교명을 넣고 **`학교 확인`** 을 누르면 AI가 학교와 그 학기의 교육과정을 먼저 파악해 요약 카드로 보여 줍니다(가능하면 Google 검색 grounding, 실패 시 프롬프트만, 키가 없으면 기본 안내). 다음 단계로 넘어가려면 이 확인을 먼저 해야 합니다.
3. **수준 · 시험일 · 목표** — 기초/보통/심화, 시험 날짜(D-day), 목표 50% / 70% / 90%
4. **하루 루틴** — 학습 시간 직접 설정 또는 **AI 추천**
5. **과목 확인** — 2단계에서 확인한 학년·학기 교육과정의 과목을 AI가 리스트로 보여 주고, ✕로 빼거나 다른 과목/직접 입력으로 추가합니다. (예전 6단계 자료 업로드는 홈으로 옮겼습니다)
6. **단원 확인** — 과목별 단원·핵심 주제 7개를 AI로 확인(키가 없으면 기본 교육과정)
7. **저장** — Google 로그인(Drive appDataFolder) 동기화 또는 로컬 저장

## 과목별 시험 범위 · 자료 → 레슨 경로 (홈)

홈(시험) 화면에서 **과목을 고르면 그 과목의 `시험 범위 · 자료` 카드**가 나타납니다.

- **📄 PDF 올리기 / 🖼️ 필기 사진 올리기** — AI가 PDF 글자나 필기·교재 사진을 읽고 시험 범위(단원·장·절)를 파악해 카드에 보여 줍니다.
- **✍️ PDF나 사진이 없어요** — `시험 범위가 무엇인가요?` 질문에 직접 적습니다. (예: `고1 공통과학 2단원~3단원`)
- 이어서 **사전 질문**(시험까지 남은 날짜 · 목표 50/70/90% · 지금 이해도 · 학년·학기)에 답하면, AI가 **개념 학습 → 암기 → 기본 문제 → 응용 → 실전 모의고사 → 구술** 순서의 듀오링고식 레슨 경로를 새로 만들어 홈 학습 경로를 교체합니다. 이미 끝낸 레슨은 제목이 같으면 유지됩니다.
- 올린 자료와 범위는 과목별로 저장되어 튜터·퀴즈·카드·계획·팟캐스트 프롬프트에 `이번 시험 범위`로 함께 들어갑니다.

## 수업 후 난이도 평가 → AI 자동 조절

- 레슨(개념 튜터 · 플래시카드 · 퀴즈 · 모의고사 · 구술 · 팟캐스트 · 시뮬레이션)이 끝나면 **"이번 수업은 어땠나요?"** 모달이 떠서 `😵 어려웠어요` / `🙂 보통이에요` / `😌 쉬웠어요`를 고를 수 있습니다.
- 선택은 **과목별로 저장**되고(최근 20회 기록), 그 과목의 모든 AI 프롬프트(개념 설명, 튜터 힌트, 퀴즈·모의고사 출제, 카드, 계획, 팟캐스트, 구술)에 반영됩니다.
  - 어려웠어요 → 선수 개념부터, 일상 비유, 아주 작은 단계, 힌트를 더 많이, 쉬운 문제부터
  - 보통이에요 → 지금 수준 유지
  - 쉬웠어요 → 설명은 압축, 심화·응용·함정·서술형 비중 확대
- 홈의 난이도 필(🎚️)을 누르면 언제든 직접 바꿀 수 있고, 설정 → 수업 난이도에서 과목별 상태를 볼 수 있습니다.

## 화면

- **홈(시험)** — Astra 스타일 학습 경로. 폴더 탭(과목 진도 링), 큰 단원 제목(AI 교육과정에서 온 단원), D-day·목표 필, 3D 레슨 노드(완료 ✓ / 현재 글로우 / 잠금), `다음 수업 시작하기`
- **과목 시트** — 상단 과목 바를 누르면 과목 아이콘 가로 배열 · 현재 과목 진도 카드 · "신규 과정"(＋ 과목 추가)
- **랭킹** — 주간 XP 리그(브론즈~다이아몬드), 나와 친구 공유 코드/링크로 추가한 친구만 표시, 배지, 통계
- **설정** — 학습 정보(학년·학기·나이 포함)·과목·시험 설정 수정, **수업 난이도(과목별)**, **AI 교육과정 다시 확인**, **화면 테마(다크 / 화이트 모드)**, API 키 관리, Google Drive 동기화 Client ID/로그인, JSON 내보내기·불러오기, 자동 읽기·속도·모드·하루 목표, 데이터 초기화, 개인정보 안내

## 테마와 AI 교육과정

- **화이트 모드** — 설정 → 앱 설정 → 화면 테마에서 `🌙 다크 모드` / `☀️ 화이트 모드`를 고르면 `localStorage`에 저장되고, 다음 방문에도 그 테마로 열립니다. 두 테마 모두 상단바·과목 시트·시험 카드·레슨 노드·랭킹·설정·튜터·퀴즈·모의고사에서 같은 대비를 유지합니다. (온보딩 마법사는 Astra 다크로 고정)
- **AI 교육과정** — 과목별 단원과 핵심 주제 7개를 Gemini로 확인합니다(가능하면 Google 검색 grounding 시도 후 실패하면 교육과정 프롬프트만 사용). 설정에서 국가·학교급·학년·학교명·교육과정 메모를 고쳐 저장하면 바뀐 조건으로 자동으로 다시 확인해 과목별 단원을 갱신하고, 진행 상황과 완료 안내를 보여 줍니다. 과목을 새로 추가해도 그 과목의 교육과정을 바로 확인합니다. 기존 학습 진도는 단원명이 같은 레슨에 한해 유지됩니다.


레슨 노드는 기존 기능으로 바로 이어집니다: 💬 1:1 튜터 · 🃏 플래시카드 · 📝 퀴즈 · 🔬 시뮬레이션 · 🎧 팟캐스트 · ⏱️ 모의고사 · 🎤 구술 시험

캐시버스팅: `python3 tools/build.py` 로 `?v=<content hash>` 를 붙인 뒤 커밋·푸시합니다.

## 리그 규칙

- 이번 주(월~일) 획득 XP로 티어가 정해집니다: 브론즈 0 · 실버 100 · 골드 250 · 사파이어 500 · 루비 900 · 다이아몬드 1500
- 하루 목표 XP를 채우면 연속 학습일이 이어집니다.
- 친구 랭킹은 서버 없이 **공유 코드/링크**로 동작합니다. (스냅샷 방식)

## Google Drive 동기화 (선택)

정적 사이트이므로 OAuth Client ID가 필요합니다.

1. Google Cloud Console → OAuth 클라이언트 ID(웹 애플리케이션) 생성
2. 승인된 JavaScript 출처에 배포 주소(`https://junub9318-pixel.github.io`) 추가
3. Drive API 사용 설정
4. 앱 **설정 → 학습 저장 · Google Drive → Client ID 설정**에 붙여넣고 Google 로그인

로그인은 실제 Google 계정으로만 동작하며(가짜 로그인 없음), 백업 파일은 내 Drive의 앱 전용 폴더(appDataFolder)에만 저장됩니다. API 키는 백업에 포함되지 않습니다.

## 기술

- 순수 HTML/CSS/JS (ES modules), 빌드 없음
- Gemini `generativelanguage.googleapis.com/v1beta` REST 브라우저 직접 호출 (`x-goog-api-key`)
- KaTeX(수식), PDF.js(자료 텍스트 추출), Web Speech API(음성), Google Identity Services(동기화)
- AI 시뮬레이션은 `iframe sandbox="allow-scripts"` 안에서만 실행
- GitHub Pages `Cache-Control` 대응: `python3 tools/build.py`가 파일 해시를 `?v=`로 붙입니다

## 개인정보

- API 키·대화·기록은 localStorage에만 저장되고 서버로 보내지 않습니다. (요청은 Google Gemini API로만)
- 학교 공용 PC에서는 사용 후 **설정 → API 키 삭제**를 눌러 주세요.
- 설정 → JSON 내보내기/불러오기, Drive 백업으로 기기를 옮길 수 있습니다.
